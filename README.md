# Clothing Store Suite

سامانه فروش پوشاک شامل دو اپ اندرویدی مستقل (Kotlin + Jetpack Compose + Material 3):

- `admin-app` — مدیریت فروشگاه (تم مشکی و طلایی)
- `customer-app` — فروشگاه مشتریان (تم روشن کرم)
- `shared-core` — منطق مشترک بدون وابستگی به اندروید (قیمت‌گذاری، موجودی، سفارش، حسابداری، تقویم شمسی)

## ساخت
Push به شاخه `main` در GitHub Actions اجرا می‌شود: ابتدا تست‌های `shared-core`، سپس ساخت هر دو APK.

## وضعیت
- مرحله ۱: منطق مشترک و تست‌ها (انجام شد)
- مرحله ۲: ذخیره‌سازی رمزنگاری‌شده‌ی محلی و اپ مدیر (داشبورد، کالاها، مشتریان و حساب مشتری) (انجام شد)
- اپ مشتری هنوز نمایشی است.

جزئیات در `docs/architecture/ARCHITECTURE.md`.
