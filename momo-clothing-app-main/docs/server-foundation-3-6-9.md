# زیرساخت گزینه‌های ۳، ۶ و ۹

این نسخه بدون سرور همچنان آفلاین کار می‌کند و هیچ درخواست شبکه‌ای ارسال نمی‌کند. مدل‌های مشترک آماده‌اند تا بعداً با API واقعی وصل شوند.

## گزینه ۳: سبد خرید و سفارش

منطق فعلی شامل تغییر تعداد، حذف کالا، کنترل موجودی، کوپن، محاسبه مبلغ و هزینه ارسال است. قرارداد `CartSyncRequest` برای همگام‌سازی سبد بین گوشی و سرور آماده شده است.

پیشنهاد API:

- `POST /v1/cart/sync`
- `GET /v1/cart`
- `POST /v1/orders`
- `GET /v1/orders/{id}`

## گزینه ۶: اعلان‌ها

صف اعلان پنل مدیریت و `NotificationDraft` قبلاً وجود داشت. مدل `NotificationMessage` برای ارسال اعلان درون‌برنامه‌ای و Push آماده شده است.

پیشنهاد API:

- `POST /v1/notifications`
- `GET /v1/notifications?deviceId=...`
- `POST /v1/devices/register`
- `POST /v1/notifications/{id}/read`

برای اعلان بالای گوشی، بعداً FCM یا سرویس Push سرور به این لایه متصل می‌شود. کلیدهای FCM نباید داخل APK قرار بگیرند.

## گزینه ۹: کمپین، تخفیف و بنر

`Campaign` برای کمپین تخفیف و `HomeBanner` برای بنر صفحه اصلی آماده شده‌اند. فعلاً بنرهای فعلی و قیمت‌گذاری آفلاین تغییر نکرده‌اند تا رفتار برنامه ثابت بماند.

پیشنهاد API:

- `GET /v1/home/banners`
- `GET /v1/campaigns/active`
- `POST /v1/admin/campaigns`
- `POST /v1/admin/banners`
- `PATCH /v1/admin/campaigns/{id}`

## اطلاعات مورد نیاز هنگام خرید سرور

- دامنه یا IP سرور
- نوع دیتابیس، ترجیحاً PostgreSQL
- دامنه HTTPS
- روش احراز هویت پنل ادمین
- سرویس Push، در صورت نیاز به اعلان خارج از برنامه

تا وقتی `ServerFeatures` فعال نشود، برنامه هیچ وابستگی به اینترنت یا سرور ندارد.
